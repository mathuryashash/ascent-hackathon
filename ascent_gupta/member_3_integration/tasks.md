# Tasks for Member 3: Full-Stack & Integration Specialist (Lead: Ingress, UI & Tracing)

## Primary Responsibility
Building the "Window" and the "Pipe". You connect the webhook ingress to the graph and build the dashboard that judges will use to visualize the AI's "Deep Reasoning."

---

## Phase 1: API & Integration (Hour 0 - 6)
- [ ] **FastAPI Ingress Node:**
    - Create the `/webhook` endpoint.
    - Implement a Redis-based message queue (or simple Python Queue) to handle incoming alerts asynchronously.
- [ ] **State API:**
    - Create a `/status/{trace_id}` endpoint that queries the LangGraph SQLite store to return the current state of a run.

## Phase 2: Observability & Tracing (Hour 6 - 16)
- [ ] **Omium SDK Integration:**
    - Ensure every node transition in the graph is recorded as a "Verifiable Trace" via Omium.
- [ ] **Structured Logging:**
    - Use `structlog` to output JSON logs of all agent thoughts and tool results.
- [ ] **Prometheus Metrics:**
    - Implement a `/metrics` endpoint tracking `runs_total`, `success_rate`, and `avg_resolution_time`.

## Phase 3: Frontend Dashboard (Hour 16 - 24)
- [ ] **The "Thinking" UI (React/Streamlit):**
    - Build a real-time dashboard that polls the status API.
    - Visualize the **Mermaid Diagram** and highlight the "Active Node."
    - Show a "Reasoning Terminal" that streams the agent's thought process.
- [ ] **The "Patch Preview":**
    - Show the "Before vs. After" code diff generated by the Architect.
    - Add a "Manual Approve" button for the human-in-the-loop requirement.

## Final Delivery
- [ ] **Deployment:** Deploy the Orchestrator and UI to a public URL (Vercel/Railway).
- [ ] **The "Perfect Run" Video:** Record a high-quality 2-minute video of the end-to-end demo as a backup.

## Handover Deliverables
1. `main.py` (FastAPI server).
2. `frontend/` directory (React/Streamlit app).
3. `metrics.py` and `tracing.py` modules.
