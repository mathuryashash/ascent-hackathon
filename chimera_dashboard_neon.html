Overview

Project Chimera is a modular AI orchestration platform that brings together autonomous agents and a suite of machine‑learning models to provide end‑to‑end data ingestion, processing, inference, and result delivery. The system runs in isolated Docker containers, enabling rapid experimentation, reproducible environments, and easy scaling across compute resources.

Agents

Agent Name Purpose / Function Implemented In Key Dependencies
Data Ingestion Agent Collects raw data from APIs, file systems and streams. Python (FastAPI) requests, pydantic, aiohttp
Pre‑Processing Agent Cleanses, normalises and enriches incoming data. Python (Pandas, spaCy) pandas, spaCy, nltk
Inference Agent Routes data to the appropriate ML models and aggregates predictions. Python (Torch, Transformers) torch, transformers, sentence‑transformers
Post‑Processing Agent Formats model outputs, persists results, and triggers notifications. Node.js (Express) express, pg, socket.io
