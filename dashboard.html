Description

Project Chimera is an integrated AI orchestration platform that combines multiple autonomous agents and diverse machine‑learning models to deliver end‑to‑end data processing, inference, and result delivery pipelines. The platform is containerised, highly modular and designed for rapid experimentation across LLMs, NLP classifiers, vision models, and generative AI.

Agents

Agent Name Purpose / Function Implemented In Key Dependencies
Data Ingestion Agent Collects raw data from APIs, file systems, and streams. Python (FastAPI) requests, pydantic, aiohttp
Pre‑Processing Agent Cleanses, normalises and enriches incoming data. Python (Pandas, spaCy) pandas, spaCy, nltk
Inference Agent Routes data to appropriate ML models and aggregates predictions. Python (Torch, Transformers) torch, transformers, sentence‑transformers
Post‑Processing Agent Formats model outputs, persists results, and triggers notifications. Node.js (Express) express, pg, socket.io
